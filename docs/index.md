# 東彁総合研究所 公開記録保管庫

記録編纂課が公開対象として整理した調査報告書および関連資料を保管しています。

## 公開記録を読む

公開済みの記録は、リポジトリ内の [`archives/`](https://github.com/lafcadio896-cyber/tokka-public-archives/tree/main/archives) から参照できます。

各記録には、報告書本文、公開用画像、最終整理済みJSON、投稿用テキストが含まれます。

## 注意事項

本サイトおよびリポジトリに掲載される組織、施設、地名、人物および事象は架空のものです。実在の組織・人物・事件とは関係ありません。
