# 津雲（つくも）化学工業株式会社における製品同梱文書の改訂履歴に関する調査報告

**記録日:** 2026-01-20

## 1. 調査の背景

津雲化学工業株式会社品質保証部では、主力製品である工業用洗浄剤「T-Clean Pro 500」の製品リニューアルに伴い、同梱されている「取扱説明書」および「安全データシート（SDS）」の全面改訂作業を進めていた。その過程において、現行の取扱説明書（Ver.4.2）に含まれている一部の注意書きについて、その記載根拠となる技術データやリスク評価書が存在しないことが社内監査で指摘された。具体的には、「使用後の容器廃棄」に関する項目において、一般的な廃棄手順とは異なる特殊な処理フローが記載されており、その制定経緯を確認する必要が生じたため、過去の改訂履歴および関連文書の調査を実施した。

## 2. 調査対象および方法

調査対象は、「T-Clean Pro 500」が発売された2010年から現在に至るまでの、すべての版の取扱説明書、改訂申請書、品質会議議事録、および顧客からの問い合わせ履歴である。調査期間は2026年1月10日から1月20日。

文書管理システムに登録されているPDFデータおよび総務部書庫に保管されている紙媒体の原本を照合し、当該注意書きがいつ、どのような理由で追加されたかを追跡した。また、当時の製品開発担当者および品質保証責任者（退職者含む）へのメールおよび電話によるヒアリングを行った。

## 3. 調査結果の整理

問題となっている記述は、取扱説明書裏面の「廃棄上の注意」セクションにある以下の文言である。

『容器を廃棄する際は、必ず中身を完全に使い切った後、蓋を閉めた状態で3回以上強く振り、音がしないことを確認してから廃棄区分に従ってください。音がする場合は、直ちに蓋を開け、屋外で24時間放置してください。』

調査の結果、この文言は2014年改訂のVer.2.0から突如として追加されていることが判明した。Ver.1.0（2010年版）およびVer.1.5（2012年版）には、このような記述は一切見当たらない。また、製品の化学成分や容器の仕様は発売当初から変更されておらず、物理的に「振ると音がする」ような固形物が生成される化学的メカニズムも確認されていない。技術開発部の見解としても、「液体洗剤の容器から音がすることはあり得ない」との回答であった。

## 4. 従来の運用・説明との比較

従来、この記述は「ガス発生時の内圧上昇を確認するための簡易チェック法」として社内で解釈され、新人研修等でもそのように説明されてきた。しかし、今回の調査で2014年の改訂申請書（Change Request No.14-058）を確認したところ、改訂理由欄には「顧客要望への対応および記載適正化」と記されているのみで、具体的な技術的根拠や、「音がする」という事象の具体的な定義についての記載は欠落していた。

さらに、顧客からの問い合わせ履歴（過去15年分、約3万件）を全件検索したが、「容器から音がする」というクレームや質問は1件も存在しなかった。つまり、「顧客要望への対応」という改訂理由自体が、事実に基づかない虚偽の記述、あるいは別の意図を含んだ記述であった可能性が高い。従来の説明であった「ガス発生リスクへの対応」という理屈も、SDS上の危険有害性情報（ガス発生なし）と矛盾しており、論理的に破綻していることが明らかとなった。

## 5. 追跡調査・再整理で判明した点

改訂が行われた2014年当時の品質保証部長であった人物（故人）の手帳および個人メモが、社史編纂室に残されていたため、これを確認した。その中に、2014年5月の日付で「北関東工場のライン停止トラブル」「異音混入」「封印」という断片的な記述が見つかった。同時期に北関東工場では、充填ラインのセンサー誤作動により、数日間の稼働停止が発生していた記録がある。

当時の工場作業員へのヒアリングでは、「空のボトルからカラカラという音がするロットがあったが、中を見ても何も入っていなかった」「気味が悪いので全て廃棄したはずだ」という曖昧な証言が得られた。しかし、品質異常報告書として正式に記録されたものはなく、不適合品の廃棄証明書も発行されていない。

これらの情報から推測されるのは、2014年に工場内で何らかの「説明のつかない異音現象」が発生し、それが製品欠陥として市場流出することを恐れた当時の管理職が、根本原因を特定できないまま、対症療法的な免責事項として取扱説明書に不可解な手順を追加した、という経緯である。「音がしないことを確認しろ」という指示は、裏を返せば「音がするものが混入している可能性がある」ことを当時の担当者が認識していたことを示唆している。

## 6. 今後の対応・検討事項

本件記述について、現在の技術的知見および法規制の観点からは無意味かつ不要な手順であると断定できる。しかしながら、削除した場合に万が一「音がする容器」が発見された際、製造物責任法上のリスク回避ができなくなる懸念が法務部より示された。

「音がする」という現象の実態が不明（物理的な異物混入なのか、その他の要因なのか）であり、かつ過去10年以上にわたり市場からのクレームがないことから、当該記述を削除することによるメリットよりも、現状維持によるリスクヘッジ（と称した思考停止）の方が得策であるとの判断に至った。

よって、次期改訂版（Ver.5.0）においても、当該記述は文言をそのまま踏襲することとする。ただし、社内向けのQ&A集においては、「念のための確認手順であり、通常は音はしない」という回答を標準とし、背景にある経緯については「記録なし」として情報の遮断を図る。本件に関するこれ以上の深掘り調査は実施しない。
