# 東彁総合研究所 公開記録保管庫

東彁総合研究所 記録編纂課が、公開対象として整理した行政文書風の創作記録を保管するリポジトリです。

## 公開記録

公開済みの記録は `archives/` 以下に保存されます。

新形式の記録は原則として次の2ファイルだけで構成します。

- `report.md` — 読者向け本文
- `meta.json` — 一覧表示用の最小メタデータ

画像、最終整理済みJSON、投稿用テキストは必須ではありません。旧形式の記録にはこれらのファイルが残っていますが、公開サイトでは本文を中心に閲覧します。

## 公開頻度

日次の自動生成・自動公開は行いません。制作したい時に1件または複数件をまとめて作成し、確認後に随時公開します。

## 記録の取扱い

内容の訂正、表示上の問題、公開範囲に関する連絡はIssueから受け付けます。詳細は `PUBLICATION_POLICY.md` を参照してください。

## 創作物であることについて

本リポジトリに掲載される組織、施設、地名、人物および事象は架空のものです。実在の組織・人物・事件とは関係ありません。

## 権利表記

掲載文書、画像、設定および構成の権利は作者に留保されます。無断転載、再配布、学習データ化、商用利用は許可していません。詳細は `RIGHTS.md` を参照してください。
